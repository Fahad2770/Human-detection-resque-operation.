
# 🚨 Dual-Purpose Wi-Fi Life & Security Sensing Hub
An open-source IoT system designed for **Earthquake Disaster Rescue** and **Smart Home Security** using ESP32 and Wi-Fi RSSI variance analysis.

## 🌟 Key Features
- **Disaster Rescue Mode:** Detects sub-debris human respiration and micro-movements after building collapses.
- **Smart Home Security Mode:** Acts as an invisible motion and intrusion detector without cameras.
- **Real-time IoT Dashboard:** Built using Python and Streamlit Cloud with signal filtering and posture mapping.
- **Low Cost & Open Source:** Powered by ESP32 microcontrollers.
